# Icon sources

The technology and contact artwork uses recognizable SVG marks from:

- [Simple Icons](https://github.com/simple-icons/simple-icons), under [CC0 1.0](./licenses/simple-icons.md). Source revisions: `0af835e2949a9222965522780e5e0810d3c53382` and `43e5f038f228b3141d353d16a81ac6d6fbf231cf`.
- [Devicon](https://github.com/devicons/devicon), under the [MIT license](./licenses/devicon.txt). The Java mark comes from revision `6910f0503efdd315c8f9b858234310c06e04d9c0`.

Original SVGs and per-icon source URLs are retained in [the source catalog](../icon-sources.json). Dark marks use lighter foreground colors on the profile's dark backgrounds; the Java icon retains its source colors.

The surrounding tiles, labels, and contact-button layouts are generated by [profile_icons.py](../../scripts/profile_icons.py). Brand names and marks identify the technologies and services linked from the profile.
